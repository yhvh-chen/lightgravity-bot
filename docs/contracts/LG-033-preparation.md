# LG-033 资料摄取与检索契约准备稿

> **性质：准备稿，非契约冻结。** 本文件不修改 [docs/08 接口契约](../../docs/08-interface-contract.md)，
> 不升 `CONTRACT_VERSION`（当前 `1.5.0`），不定义已冻结语义。正式冻结必须由 LG-033 实施者按 docs/08 §13
> 变更控制升版。资料方向见 [docs/09](../../docs/09-source-intake-and-retrieval.md)（方向已确认、接口未冻结）。

## 1. 目标与边界

- 目标：把 docs/09 的资料方向收敛为**可实施接口**，文件仍是唯一事实源（原件＋资料 frontmatter/正式内容文件为权威；JSONL 保存历史）。
- 保持：索引/向量仅为可重建缓存；权限与归属不存于索引，读取时回源核对；摄取作业不自动创建交付 Task/Run/团队。
- 不做：通用知识库平台、独立向量数据库服务、多租户、邮箱全箱同步、自动执行邮件指令。

## 2. 待冻结协议面（候选，未冻结）

1. **来源记录 schema**：原件、机器提取、人工正式版本分层；内容 hash 与 stat revision 严格区分。
2. **摄取作业**：有界、可取消、可恢复；幂等请求 ID；失败不造空成功正文；失败说明不参与检索。
3. **受控收件区**：归属未知资料落点；全局上传不强建 Task；实质歧义才询问。
4. **回执**：按文件区分 已收到/处理中/成功/部分成功/失败，含来源、产物位置、可检索性、失败原因。
5. **查询接口**：授权候选 → 回源核对存在/哈希/版本/权限 → 真实位置；来源撤销/删除使命中失效。
6. **幂等/去重/来源版本**：同一来源+内容 hash 去重（作用域内）；跨来源/跨 Task 不合并权限；来源 hash 变化生成新源版本并失效旧命中；重处理不覆盖人工校订。
7. **索引/向量模型版本**：内容哈希、更新失效、可重建缓存边界；权限和归属不可只存在索引。
8. **版本化接口、事件、开关与兼容迁移计划**：实施前按 docs/08 §13 升版，并处理与既有 Files/Chat 契约的共享冲突。
