# LG-003 — 验证 Antigravity SDK 核心能力

## 目标

在明确测试环境验证实际安装版本的 SDK 核心能力。

## 范围

阶段：基础与探针。仅实施本项所需首版能力；不扩展多后端、组织、云端或外部渠道。

## 验收条件

- 记录 SDK/runtime/平台版本，真实验证 skills、文件操作、网页工具和结构化输出。
- 验证工具事件、取消、预算停止、保存/恢复与实际沙箱状态，不支持项明确报告。
- 有可复现探针和报告，认证/预算缺失时保留未验收，不用源码存在代替运行成功。

## 依赖

LG-002 为接口或实际交付需要，不是单纯阶段排序。

### 未验收/阻塞（真实理由）

- **Gemini Developer API 与 Vertex 后端未验收**：本环境无 `GEMINI_API_KEY`/Vertex 凭证，会话启动抛 `AntigravityValidationError`。产品首版 Gemini 契约符合性必须在有凭证环境重跑探针后确认；此项 `blocked`，不代表本任务其他能力未验证。
- `search_web` 在 OpenAI-compatible（非 Gemini）端点下返回无可结果，实际不可用。
- subagents/workflows/MCP/Triggers/多模态/图像生成未做真实调用（首版默认关闭或范围外）；沙箱仅确认 runtime 报告状态，未做逃逸验证；仅 x86_64 Linux wheel 实测。
- SDK 的 OpenAI/Gemma endpoint 无 api_key 字段，非 Gemini 后端需外部注入凭证；未擅自改产品首版 Gemini 契约。
