# LG-002 — 建立可运行工程骨架

## 目标

建立后端、前端、测试和配置的最小工程。

## 范围

阶段：基础与探针。仅实施本项所需首版能力；不扩展多后端、组织、云端或外部渠道。

## 验收条件

- 干净环境可启动健康端点和前端壳，版本与平台要求明确。
- 测试、类型和构建入口可用，示例配置无真实凭证。
- 不依赖参考克隆与开发机绝对路径，数据目录与源码分离。

## 依赖

LG-001 为接口或实际交付需要，不是单纯阶段排序。

状态：**完成（待版本 QA）**。执行者 `agent:pi-lg002`，2026-10-15；本项为工程骨架，按 agent.md 做局部检查，不设逐任务独立 QA。

- 干净环境可启动健康端点与前端壳，版本/平台要求明确：README 记录版本要求；uvicorn 与 Vite dev server 均实际启动并 curl 验证。
