# LG-027 — 验收模型设置与凭证生命周期

## 目标

专项验证首次接入、凭证/默认变更、测试与界面反馈的完整路径。

## 范围

阶段：首版验收。首版先 Gemini；其他 SDK 后端只展示验证状态，不扩大为多后端实现或云端发布。

## 验收条件

- 缺认证启动→Settings 配置→分层测试→设默认→新 Task 执行有真实路径证据；网络成功不能当作全部能力通过。
- 认证错误、模型不存在、超时/取消、配置冲突、凭证更新测试过期、移除/禁用被引用连接的处理可复现。
- 检查秘密不进入持久浏览器状态、聊天、任务文件、日志、响应或导出；部分写入故障不会无提示留下孤立秘密/坏引用。
- 修改默认时活跃 Member 保持旧配置，新招募采用新版本；返回原 Task 和窄屏输入行为有效。
