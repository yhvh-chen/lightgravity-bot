## 验收条件（完整）

- **英文主线**：upload → select → answer / source open 全路径真实通过。
- **选定资料交付**：→ artifact / reviewer / accept + 停止确认。
- **无选材路径**保持不变（legacy 省略字段行为不变）。
- **真实错误**：stale / revoked / cross-Task / oversize 均产生**真实错误**，不得吞掉或伪造成功。
- **窄屏 390 / 1024 / 1440** + 过渡无溢出。

- 覆盖契约 `1.12.0` 加性字段、旧客户端兼容、错误码语义。
