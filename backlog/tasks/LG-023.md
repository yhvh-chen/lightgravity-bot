# LG-023 — 完成单 agent 对照评估

## 目标

评估组队相对单 agent 的真实交付收益。

## 范围

阶段：首版验收。仅实施本项所需首版能力；不扩展多后端、组织、云端或外部渠道。

## 验收条件

- 固定任务输入、版本、资源约束和验收条件。

- 可复现且说明样本局限和不适合组队场景，不用角色数量代替收益。
