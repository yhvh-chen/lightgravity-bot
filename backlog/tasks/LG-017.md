# LG-017 — 实现独立 QA 与有限返修

## 目标

实现结构化 QA 问题和有限返修。

## 范围

阶段：恢复与质量。仅实施本项所需首版能力；不扩展多后端、组织、云端或外部渠道。

## 验收条件

- 独立 QA 检查候选版本，问题引用真实证据与返修目标。
- 业务返修与 SDK 重试分开，达到预算/轮数停止。
- 拒绝验收保留旧交付，原 Task 新尝试重新组队并复验。

## 依赖

LG-009、LG-016 为接口或实际交付需要，不是单纯阶段排序。

## 验证记录

实施已完成（本地，待版本 QA）。基点 `141809d`，契约 docs/08 `1.6.0`（加性、不变更枚举/迁移/错误码）。

变更（owner 范围内文件）：
- 新增 `backend/lightgravity/verify/review.py`：独立 reviewer 端口 + 确定性 `ProgramReviewer`；
  `validate_findings` 程序校验 finding 必须引用可解析的候选证据，`unavailable` 不假 pass。
- 新增 `backend/lightgravity/verify/rework.py`：`ReworkOrchestrator`、Task 终身账本（跨 Run 不重置）、
  `RunSpawner`/`SpawnOutcome`、有界返修轮数。
- 修改 `backend/lightgravity/coordinator/service.py`：`set_rework`、惰性默认真实闭环、
  `spawn_repair_run`（候选/证据保留，新 Run 重新招募+复验）、`_auto_verify` 先复核后验收、
  Run attempt 递增、rework 指令注入。
- 修改 `backend/lightgravity/api/tasks.py`：人工 `reject` 触发新 Run；重复 reject 幂等复放 `rework` 字段。
- 未改 `api/app.py`/frontend/graph.py/scheduler.py/dispatcher.py/adapter；docs08 仅提案（`probes/lg017/`）。

命令与结果（本地，真实执行输出）：
- `uv run mypy` → Success, 93 files。
- `uv run pytest tests/verify tests/coordinator tests/api tests/control -q` → 245 passed。
- `uv run pytest -q`（全后端）→ 502 passed, 4 skipped。

证据类型：测试与集成为 mock/进程内替身（unit/local evidence）；真实 SDK/DeepSeek 端到端未在本包运行（0 次真实模型调用），归 LG-021/022 版本门。
未测限制：真实独立 reviewer（模型后端的 reviewer 仅提供端口，默认实现为程序化确定性 reviewer）；真实多 worker 隔离；浏览器路径。
集成说明与 schema/调用点见 `probes/lg017/INTEGRATION.md`；docs08 变更提案见 `probes/lg017/DOCS08-PROPOSAL.md`（由集成 owner 单独落 docs08）。
