## 目标

在实现前，由**唯一契约 owner（`pi-proto-prepare`）**完成**快速原型（selected-material）**的接口冻结与工作包定界：读现有消息 API/DTO、bootstrap/coordinator/adapter、前端选材与资料 API 路径，落盘一份**精确、可实现、向后兼容**的契约，并准备三份并行 worktree 的派工说明。

## 验收条件

- 契约文档给出**精确字段名**、共享 TS shape、状态值、错误码；**不破坏 legacy 省略字段**（新增字段全部 optional，旧客户端不传仍可用）。
- 请求侧：**可选 selected source refs**，形状以实际模型允许为准（`source_id` + `version`/`hash`）。
- 响应侧：程序解析后的 `resolved source bindings`，含 version/hash/layer/locator 与 **truncation info**；程序侧解析而非模型侧。
- 选定资料规则：仅对**已摄取**资料手动选择，**最多 3 个来源**、总 **≤12000 Unicode 字符**、有界读取；超长则**显式截断并附 metadata** 或**沿用既有 limiter 拒绝**；冻结明确选择。
- 正式优先、机器派生回退；**仅用已信任机器**，不做 OCR/重处理/新推理。
- 复用既有 `SourcesService` 的 availability/scope 安全解析器与受控路径；**stale/revoked/missing/unreadable/cross-Task** 在**模型派发前显式拒绝**；worker 派发前**重新校验**，不得绕过 stale 权限。
- 选定资料作用域为 **global/Task UI**，**不跨 Task 携带**；资料正文视为**不可信数据**，以分隔符隔离、**不当作指令**。
- 持久化：message/run 保存版本/哈希引用与**有界上下文快照**，用既有受控 SoT；恢复/重放**不重新解析不同内容**。
- 明确错误行为、selection 清除/发送 pending、旧前端兼容行为。
- **无重复不兼容 DTO**；API 公开加性变更 ⇒ 契约 MINOR `1.12.0` 预留。
- 记录 PM 决策到 `PROJECT.md`（短段）+ `BACKLOG.md` 链接 + `PROGRESS.md`（当前 protototype in-progress）；`DISPATCH.md` 含每 worker REPORT 早发/最后 10 轮预留提交的说明。
- 任务状态只在任务 frontmatter 维护；**不置 done 以外的虚假验收**；claim `pi-proto-prepare` 后 bounded 技术准备并提交证据。
