- 契约文档给出**精确字段名**、共享 TS shape、状态值、错误码；**不破坏 legacy 省略字段**（新增字段全部 optional，旧客户端不传仍可用）。
- 请求侧：**可选 selected source refs**，形状以实际模型允许为准（`source_id` + `version`/`hash`）。
- 响应侧：程序解析后的 `resolved source bindings`，含 version/hash/layer/locator 与 **truncation info**；程序侧解析而非模型侧。
- 选定资料规则：仅对**已摄取**资料手动选择，**最多 3 个来源**、总 **≤12000 Unicode 字符**、有界读取；超长则**显式截断并附 metadata** 或**沿用既有 limiter 拒绝**；冻结明确选择。
- 正式优先、机器派生回退；**仅用已信任机器**，不做 OCR/重处理/新推理。
- 复用既有 `SourcesService` 的 availability/scope 安全解析器与受控路径；**stale/revoked/missing/unreadable/cross-Task** 在**模型派发前显式拒绝**；worker 派发前**重新校验**，不得绕过 stale 权限。

- 明确错误行为、selection 清除/发送 pending、旧前端兼容行为。
