# LG-040 — 集中验收资料接入与 Embedding 版本

## 目标

独立验收从 Chat 输入到成文、检索回源的整合候选。

## 范围

资料接入与 Embedding 版本；LG-041 为后续中文转写扩展。本次仅排期，未启动实施。无外部聊天渠道、多租户、全邮箱同步或自主触发。

## 验收条件

- 独立于实施者的 pi 执行者覆盖浏览器真实上传、归属、OCR、校订、检索、重处理、撤销删除及索引重建。
- 验证并发/幂等、取消/重启、跨 Task 权限、损坏索引、不可用向量后端与词法降级；发现问题返修并复验。
- 复核 OCR 与检索质量数据，记录摄取/重建/查询资源成本；不能仅凭样例展示或前端构建通过验收。
- 本版本必验图片/PDF/词法与可选向量路径；音频直接向量检索应验证，中文转写仅在 LG-041 成功后另行集中验收，不阻塞本版本。
- **英文为主线（2026-10-16 用户市场范围决定）**：**优先**真实英文正文/表格/图片/查询/UI/错误流（含上传/归属/校订/重处理/撤销/重建/ACL/限制/取消/重启）与词法/向量降级；**版本 PASS 前必须完成英文主线的完整质量/端到端**。
- **中文以当前水平支持、抽样回归与已披露限制**；**中文图片排名 7 本身不再单独阻断英文导向版本的 QA**（旧中文图片硬门 FAIL 作为历史质量结果保留，不重算、不调阈值）。**安全/数据丢失/权限/假成功无论语言始终阻断**。
- **保持独立 pi QA 与原有安全/完整性门不变**；**不为英文自动添加宽泛本地化任务**，由 QA 暴露真实英文流程问题后按需返修。
- **本决定为前瞻性范围/接受决定，非追溯实验通过**；**不表示英文 E2E 已证明**，也**不解除 LG-041 中文 ASR 锁**（英文市场不等同支持英文 ASR）。本包**不声称已执行 QA**。
