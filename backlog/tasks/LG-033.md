# LG-033 — 冻结资料摄取与检索接口契约

## 目标

把 docs/09 的资料方向收敛为可实施接口，文件仍为唯一事实源。

## 范围

资料接入与 Embedding 版本；LG-041 为后续中文转写扩展。本次仅排期，未启动实施。无外部聊天渠道、多租户、全邮箱同步或自主触发。

## 验收条件

- 定义来源记录、原件/机器提取/人工正式版本、摄取作业、受控收件区、回执及查询接口；与 Task/Run 分离。
- 明确幂等请求与来源版本、跨 Task 去重不合并权限、撤销与删除、重处理不覆盖人工校订、恢复与取消。
- 定义索引/向量模型版本、内容哈希、更新失效与可重建缓存边界；权限和归属不可只存在索引。
- 按 docs/08 §13 冻结新增 schema/API 并升版；规划阶段仍保持当前 1.5.0。

## 依赖

LG-004、LG-012、LG-014 为接口或集成交付依赖。
