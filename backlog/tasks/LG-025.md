# LG-025 — 实现模型设置与凭证后端接口

## 目标

实现 Connection/SETTINGS.md 的统一受控写入、秘密引用、默认模型与分层测试接口。

## 范围

阶段：配置接入基础。首版先 DeepSeek（OpenAI-compatible）；其他 SDK 后端只展示验证状态，不扩大为多后端实现或云端发布。

## 验收条件

- Settings 与 Resources 读写同一 Connection，默认只保存引用；版本冲突、禁用/删除默认引用与跨文件部分失败可恢复。
- 明确选择后端秘密存储，支持更新/保留/移除凭证；响应、日志、事件、任务导出不泄露秘密，敏感写接口验证来源与保护。
- 首版真实测试 DeepSeek（OpenAI-compatible）：配置、认证、模型响应与可选工具/结构化探针分开；超时/取消/预算有限，参数或凭证变化使旧测试过期。
- 凭证来源支持进程环境与受控 secret store 的 `credential_ref`，不假设项目 `.env` 含可用 key；Connection 管理接口与 LG-006 的 loopback 认证代理共用同一引用，不复制秘密。
- 默认选择只影响后续会话/成员，活跃 Run 固定配置；未实现后端不可作为可执行默认连接。

## 依赖

LG-004、LG-005、LG-006 为实际接口/集成交付需要。

### 秘密方案与边界（明确选择）

- 首版秘密存储选**受控目录文件 store**：路径来自既有 `LIGHTGRAVITY_SECRET_STORE`（`lightgravity.config.Settings.secret_store`，默认 `./secrets`，`.gitignore` 已排除）。目录 `0700`、文件 `0600`；写入原子并加锁；元数据只保存不透明版本号，不含值。
- 不宣称加密；保护依赖文件权限、仓库外数据目录与默认 loopback 服务。响应/事件/诊断/证据只返回 `configured`/`source`/`version`，不返回值；`Secret.__repr__` 恒为 `<redacted>`。
- 进程环境凭证只读：可解析并显示 `source=environment`，删除只清理 store 副本，不影响环境变量。
