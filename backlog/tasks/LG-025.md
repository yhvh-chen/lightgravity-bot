# LG-025 — 实现模型设置与凭证后端接口

## 目标

实现 Connection/SETTINGS.md 的统一受控写入、秘密引用、默认模型与分层测试接口。

## 范围

阶段：配置接入基础。首版先 Gemini；其他 SDK 后端只展示验证状态，不扩大为多后端实现或云端发布。

## 验收条件

- Settings 与 Resources 读写同一 Connection，默认只保存引用；版本冲突、禁用/删除默认引用与跨文件部分失败可恢复。
- 明确选择后端秘密存储，支持更新/保留/移除凭证；响应、日志、事件、任务导出不泄露秘密，敏感写接口验证来源与保护。
- 首版真实测试 Gemini：配置、认证、模型响应与可选工具/结构化探针分开；超时/取消/预算有限，参数或凭证变化使旧测试过期。
- 默认选择只影响后续会话/成员，活跃 Run 固定配置；未实现后端不可作为可执行默认连接。
