# LG-032 — 验收去中心化版本并比较全生命周期成本

## 目标

集中独立验收去中心化候选，判断质量与成本是否达到默认启用条件。

## 范围

去中心化协作版本。本次仅排期，未启动实施。无外部聊天渠道、多租户、全邮箱同步或自主触发。

## 验收条件

- 独立于实施者的 pi 执行者覆盖竞争领取、过期租约、崩溃恢复、取消、权限、交接及返修，失败须修复后复验。
- 固定相同仓库基点、任务、模型、预算、验收门与重复策略，对比当前程序调度基线与新协作路径；开发单 agent 对照 LG-023 不重复替代。
- 逐样本报告成功率、耗时、执行/QA/返修/复验/失败尝试 token 与人工介入；未完成样本不当作已交付成本，样本量及费用上限在实验前固定。
- 只有质量不退化且结果支持收益才建议默认启用；不达标保留可选开关或回退，记录结论，不以投入成本强行宣布成功。

## 依赖

LG-031、LG-022 为接口或集成交付依赖。其中 LG-022 是保留既有首版验收的排序门，不是新功能代码依赖。
