# LG-001 — 冻结首版接口与状态契约

## 目标

确定 Python 协调服务、前端构建方案及单用户本地边界，冻结 API、实体状态、资源配置和目录写入职责。

## 范围

交付阶段：基础与探针。仅实施本项所需能力，遵循根目录开发规则与当前设计；不自动扩展其他执行后端、云端或外部渠道。

## 验收条件

- 形成有版本的契约文档，明确 Task/Subtask/Run/Member、消息/事件 ID、队列和验收字段。
- 选定最小技术栈并说明依赖来源；配置失败、冲突、取消未确认等错误有明确返回语义。
- 明确 store 与 SDK adapter 接口、状态合法组合、工作区授权和验证清单；不开始实现全部业务。

## 依赖与顺序

无前置开发任务，实施前读取项目规则和相关设计。

## 验证记录

尚未执行。实施时记录实际命令、环境、产物/证据、结果与限制；未验收不置为 done。
