# LG-038 — 打通 Chat 资料接入与 Files 归档检索体验

## 目标

让用户在 Chat 交资料并得到回执，通过同一来源文件查找、整理和追溯。

## 范围

资料接入与 Embedding 版本；LG-041 为后续中文转写扩展。本次仅排期，未启动实施。无外部聊天渠道、多租户、全邮箱同步或自主触发。

## 验收条件

- Chat 上传/拖拽与链接记录打通；未抓取链接不得显示已成文，明确归属可沿用，实质歧义才追问。
- 逐文件显示接收、处理、成功/部分成功/失败，断线恢复后状态一致；全局上传不强建交付 Task。
- Files 预览/归档调整/校订/重处理/下载读取同一份状态，现有 Files 上传迁移有兼容路径，避免多入口重复流程。
- Chat 查询返回有权限、可打开的来源证据；用户明确要求交付时才衔接既有 Task/Run 与验收。

## 依赖

LG-013、LG-014、LG-034、LG-036 为接口或集成交付依赖。
