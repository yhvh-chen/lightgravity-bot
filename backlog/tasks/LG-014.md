# LG-014 — 实现 Files 与任务证据预览

## 目标

提供任务目录、上传下载与证据预览。

## 范围

阶段：左侧五入口。仅实施本项所需首版能力；不扩展多后端、组织、云端或外部渠道。

## 验收条件

- 输入/候选/交付/Run 证据归属清楚，长路径和不支持类型可处理。
- 路径/符号链接/上传冲突/外部变化/预览隔离经验证。
- 从任务到文件再返回保留范围，版本与下载一致，错误不覆盖草稿。

## 依赖

LG-004、LG-011、LG-012 为接口或实际交付需要，不是单纯阶段排序。

## 已登记接口（docs/08 1.3.0 登记，1.3.1 已实现）

- `POST /api/v1/files/upload`：有界二进制 body，带 `path` 与 `expected_revision`，限制在授权目录内并做冲突检测。
- `GET /api/v1/files/download`：有界文件下载，授权目录内、附 revision 一致性。

两端点在 [docs/08 §4.3](../../docs/08-interface-contract.md) 登记，并自契约 `1.3.1` 起标记为**已实现**；由本任务 owner 在 `backend/lightgravity/api/files.py` 内实现（该文件的写权限在本任务领取后归 LG-014，需在 LG-012 之后串行修改，见 docs/08 §11）。实现时同步 `tests/api/` 与必要的契约/README 事实。

### 变更（仅本工作包归属）

- `backend/lightgravity/api/files.py`：实现 docs/08 §4.3 登记的 planned 端点。
  - `POST /files/upload`：有界二进制 body（`MAX_UPLOAD_BYTES=10_000_000`）；`path` + `expected_revision`（`null`/缺省 = 必须不存在）；同目录临时文件 + `fsync` + `os.replace` 原子写并在每目标 `flock` 下检查；读取 body 前、替换前两次校对外部改动；`resolve_path` 拒 `..`/符号链接越界；额外拒绝解析到 secret store 的路径；写前以 `AccessPolicy.authorize(sensitive=True)` 重新保护，无可用 token 时诚实 `unauthorized`（不绕过）。
  - `GET /files/download`：有界（`MAX_DOWNLOAD_BYTES=50_000_000`）流式下载，附 `ETag`/`X-LG-Revision` 与可选 `revision` 一致性校验，`Content-Disposition: attachment`、`X-Content-Type-Options: nosniff`、`Cache-Control: no-store`。
  - `GET /files/content` 增加 stat 版 `revision`（与 download 同源同版本）。
  - `GET /tasks/{task_id}/artifacts`：读取 Task `workspace_ref` 与 acceptance 绑定字段（`candidate_ref`/`evidence_refs`/`check_records`），按目录约定（`inputs/`、`artifacts/`、`deliverables/`、`runs/`）关联输入/候选/交付/Run 证据；无 workspace 或不可达时返回空分类 + `note`，不编造。
- `frontend/src/api/files.ts`：Files 线协议类型与 `createFilesApi(runtime)`/`filesApi`；runtime token 可选注入且仅在上传时附加，只读浏览不发送；download 走原始 fetch 以取得 blob/revision。
- `frontend/src/views/files/FilesView.tsx` + `files.css`：`FilesView`（壳感知，可继承 LG-011 shell 的 `task_ref`/`run_ref`）与纯 `FilesPanel`（稳定 props/factory，供整合 owner 挂载）。文件树/面包屑；Markdown 用 `MarkdownViewer`（不执行 HTML）；安全图片经 download blob 隔离预览；HTML 明确禁用内联预览；其他类型仅下载；长路径截断 + 完整路径复制；上传错误按 `unauthorized`/`revision_conflict`/`path_outside_workspace` 原地提示，失败不覆盖文件。
- `tests/api/test_files_upload.py`、`frontend/tests/files.test.tsx`：新增局部测试。
