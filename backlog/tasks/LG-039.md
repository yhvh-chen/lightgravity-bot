# LG-039 — 验证中文语音转写后端与质量

## 目标

找出能生成可读中文文字的 ASR 路径，单独验证 Embedding Reader 的适配边界。

## 范围

资料接入与 Embedding 版本；LG-041 为后续中文转写扩展。本次仅排期，未启动实施。无外部聊天渠道、多租户、全邮箱同步或自主触发。

## 验收条件

- 先确定可用后端、许可证、模型来源和资源预算；现有 Qwen/embedding 路径失败不能泛化为所有模型均不可用。
- 预先固定有授权的人声样本、中文真值与判据，覆盖口音、噪声、长音频、时间戳与中英混合；合成语音不替代真实语音结论。
- 报告 CER、关键信息、耗时与失败率；英语 reader 的作者指标不能作为中文证据，向量输出不当转写。
- 达标给出接入建议；不达标保留失败记录和原件，明确阻塞 LG-041 的质量条件，不伪造可用能力。

## 依赖

LG-033 为接口或集成交付依赖。

## 验证记录

**结论：负结论 — 已授权候选服务 `http://192.168.8.12:11434`（llama.cpp router `b11641-843e7dcc1`，非 Ollama）不存在任何可用中文 ASR 路径。LG-041 不解锁。**

- 真实人声：Wikimedia Commons `File:Chinese language-1.ogg`（**CC BY-SA 3.0**，真人朗读，经 Commons API 核实许可；sha256 `1a8df6fbd1cff0ce6c192932cb6d1d5a8e20e551ba915896685544abb0528e9f`）。
- 推理 POST 5 次，**失败率 5/5=100%**，零自动重试，并发 1：
  `gemma4-mtp` 转写 500（model failed to load，70.4s）、`qwen3.8-27b` 转写 501（不支持音频）、
  `qwen3.8-27b` chat `input_audio` 500、`embeddinggemma-2` 转写 500（无 logits）、
  `bge-reranker` 转写 501。**成功转写 0、无输出、无时间戳、CER 不适用。**
- 服务能力：全 4 模型**无一**同时「接受音频输入」且「具备文本生成能力」；唯一声明 audio 的
  `embeddinggemma-2` 为 embeddings-only（向量≠文字，未当转写）。英文 reader 指标未作中文证据。
- 覆盖缺口如实记录：口音/噪声/长音频/时间戳/中英混合质量维度**未覆盖**（服务零输出，无法开始），
  **未声称质量门达标**。合成音频未用于质量结论。
- 证据：报告 `probes/lg039/REPORT.md`、进度 `probes/lg039/STATUS.md`、原始响应与真实人声原件 `probes/lg039/evidence/`。
- 预算实耗：服务只读 3 请求、推理 5 POST、公开下载 1.44 MiB，均在任务预算内。
- LG-041 阻塞条件：见报告 §7（需安装支持音频→文本的生成模型+匹配音频 mmproj，或引入独立授权 ASR 服务并重验）。
- 本项为**探针验证证据**，非产品 schema/API/依赖，也非 LG-040 集中验收；未做逐项独立 QA 或产品
  全量测试。后续版本集中 QA 按滚动排期进行。
- **状态含义（集成 owner 明确）**：`done` 仅指**有界可行性验证得到负结果**（本轮已测模型/路径在预算内
  未获得可用 ASR，LG-041 不解锁），**不等于完整中文质量验收**，也不泛化为“所有服务/任何模型永远
  无 ASR”；`gemma4-mtp` 加载失败不能证明该模型不支持。覆盖维度缺口（口音/噪声/长音频/时间戳/
  中英混合）仍保留未覆盖，CER 因无输出为不适用。真实样本许可与 hash 已核实，未见伪造真值。
