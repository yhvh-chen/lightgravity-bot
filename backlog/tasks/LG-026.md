- `frontend/src/views/settings/SettingsView.tsx`：Settings 页（唯一二级区 Models & Providers），读取 `GET /settings` + `GET /settings/connections` 的**同一 Connection 权威**；连接列表、选择、创建与编辑、默认协调/worker 模型；加载/空/错误/未授权状态；Task 范围由壳层保留（本页不改 Task）。导出 `SettingsView`（props 全可选，可直接作为 registry 的 `Main: ComponentType` 挂载）。
- `views/settings/ConnectionEditor.tsx`：按后端类型的表单（openai-compat 显示 model/base_url；gemini/vertex 标 planned 不可保存）、`expected_revision` 保存、`revision_conflict` 明确提示并重载最新 revision、凭证保留（留空即保留）/更新（set）/移除（clear ref + 删除 store 密钥）、enabled 与默认引用影响提示。
- `views/settings/ConnectionTestPanel.tsx`：分层 `config_parse`/`credential`/`capability(declared)`/`runtime_network`/`tool_probe`/`structured_output` 分开显示，标注 overall 与 **stale**（revision 或 credential version 变化），不把网络成功当 SDK 能力验证。
- `views/settings/DefaultsEditor.tsx`：默认引用编辑，说明“只影响新会话/招募，不热切活跃成员”，显示默认解析结果。
- `views/settings/backends.ts`：后端注册表单（仅 `openai-compat` verified/可执行；gemini/vertex planned/unavailable）。
- `views/settings/settings.css`：使用共享 tokens，≤1023px 单列堆叠，无横向滚动。
- `frontend/src/api/settings.ts`：真实 `/api/v1/settings*` 类型化客户端（list/get/create/update/test、`PUT/DELETE /settings/credentials/{ref}`、`PATCH /settings`），带 `expected_revision`/ETag 语义；秘密只写不读。
- `frontend/src/api/auth.ts`：**运行时 token 访问 helper**（本轮独占）。仅内存：`getRuntimeToken/setRuntimeToken/clearRuntimeToken/hasRuntimeToken/runtimeTokenHeaders`，可从受信本地页面注入的非持久 `window.__LG_RUNTIME_TOKEN__` 引导读取；**不写** localStorage/sessionStorage/IndexedDB/cookie/URL/草稿；token 缺失时返回 `null`，由真实请求返回 `unauthorized`，不伪造成功。供 LG-014 整合复用。
- `frontend/tests/settings.test.tsx`（9）、`frontend/tests/settings-auth.test.ts`（4）：加载/列表、不可用后端禁用、保存 revision/密钥清空与不落存储、凭证移除、revision 冲突重载、unauthorized 真实报错、分层测试与 stale、默认保存、空列表创建；auth helper 的内存/引导/清空/不落存储。
